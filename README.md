# NewJeans Shell

A **NewJeans-inspired** desktop shell built with **QuickShell (QML)** for **Hyprland**.

> **Status:** 🚧 Work in Progress
> 
> This project is still in an early stage of development. At the moment, only the core functionality is implemented and many components are still under active development.

## Features

- Built with QuickShell and QML
- Designed for Hyprland
- NewJeans-inspired visual style
- Modular architecture focused on customization

## Installation

This repository can be used on its own, but it is primarily developed as part of my personal dotfiles.

If you're looking for the complete desktop setup (Hyprland configuration, scripts, themes, wallpapers, etc.), check out my dotfiles repository:

➡️ **https://github.com/Dopanimekun/.dotfiles**

Inside the dotfiles repository, this project is included as a Git submodule.
